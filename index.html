아직 선택한 영상이 없습니다.

아래 ‘영상 자막 시작’으로 재생과 인식을 함께 시작하세요. 플레이어만 재생하면 자막은 생성되지 않습니다.

링크를 불러올 때만 YouTube 플레이어에 연결합니다.

  1. 링크를 불러오고 번역 준비와 음성 인식 준비를 각각 완료하세요.
  2. 탭 오디오 공유 시작을 누르세요.
  3. 공유 창에서 이 앱이 열린 현재 탭을 선택하고 탭 오디오 공유를 체크하세요.
  4. 연결 후 YouTube 플레이어의 재생 버튼을 직접 누르세요.

탭 소리를 받으려면 화면·영상 공유 권한도 필요합니다. 앱은 오디오만 인식하며 공유 화면을 저장·업로드하지 않습니다. 탭의 다른 소리도 들어올 수 있습니다. 마이크는 켜지지 않습니다.

비공개·연령 제한·임베드 금지 영상은 재생되지 않을 수 있습니다. 이 경우 재생 가능한 로컬 파일을 사용하세요. YouTube 자막이나 다운로드로 대체하지 않습니다. SRT는 공유 시작부터 누적된 시간이며 원본 영상의 재생 시간이 아닙니다. 광고의 음성도 인식될 수 있습니다.

    입력 대기확정 0 · 저장 가능 0

    완료된 번역만 저장합니다. 같은 언어는 원문을 저장합니다. SRT 시간은 추정치입니다. YouTube는 공유 누적 시간이며 원본 영상 시간과 다릅니다.

    번역 준비 전에는 마이크를 켜거나 음성을 전송하지 않습니다.

    로컬 영상은 기기에서, YouTube는 공식 임베드로 재생합니다. YouTube 링크를 불러오면 Google/YouTube에 연결되며 해당 서비스의 개인정보·쿠키 정책이 적용됩니다. 탭 공유는 화면 권한을 동반하지만 앱은 공유 화면을 녹화·저장·업로드하지 않습니다. 앱 서버로 영상·자막을 업로드하지 않습니다. 이 앱은 기기 내 음성 인식과 번역 모델만 사용하도록 요청하며 서버형 음성 인식으로 자동 전환하지 않습니다. 언어 모델 다운로드와 YouTube 재생에는 인터넷이 필요합니다. 첫 다운로드에는 시간과 데이터가 필요합니다. 현재 네이티브 번역은 데스크톱 Chrome 환경이 필요하며 휴대폰에서는 제한됩니다. 소리는 녹음 파일로 저장하지 않습니다. 탭을 숨기거나 영상을 일시 정지하면 인식을 중지하며, 미확정 원문은 저장하지 않습니다. 자막은 이 페이지의 메모리에만 남습니다. 새로고침하거나 닫기 전에 저장하세요.
